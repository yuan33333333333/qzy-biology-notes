# 第4章 细胞的物质输入和输出
## 第 1 节 被动运输
[[探究植物细胞的吸水和失水(质壁分离)]]

```
细胞物质输入和输出的方式
│
├── 一、 细胞内外的物质运输（单细胞/细胞与环境间）
│   │
│   ├── 1. 跨膜运输（小分子与离子，穿越磷脂双分子层）
│   │   ├── (1) 被动运输（顺浓度梯度，不消耗 ATP）
│   │   │   ├── 自由扩散：不需要膜蛋白（例：O₂、CO₂、脂溶性分子）
│   │   │   └── 协助扩散：需要膜蛋白（载体蛋白/通道蛋白，例：红细胞吸葡萄糖、水通道）
│   │   │
│   │   └── (2) 主动运输（逆浓度梯度，消耗能量）
│   │       ├── 原发性主动运输：直接消耗 ATP（例：Na⁺-K⁺ 泵）
│   │       └── 继发性主动运输：间接利用电化学势能（例：小肠上皮细胞协同吸收葡萄糖）
│   │
│   └── 2. 囊泡运输（大分子与颗粒，非跨膜，依赖膜流动性与融合，消耗 ATP）
│       ├── (1) 胞吞作用 (Endocytosis)
│       │   ├── 吞噬作用（包裹大颗粒/病原体）
│       │   ├── 胞饮作用（包绕细胞外液）
│       │   └── 受体介导的胞吞（特异性结合受体，例：吸收 LDL）
│       │
│       └── (2) 胞吐作用 (Exocytosis)
│           └── 分泌物质到细胞外（例：胰岛素、神经递质、抗体）
│
└── 二、 相邻细胞间的直接运输（植物特有，非跨膜）
    └── 共质体运输 (Symplastic Transport)
        └── 胞间连丝 (Plasmodesmata)
            ├── 小分子：通过连通的细胞质通道自由扩散
            └── 大分子（蛋白质/RNA）：通过调节通道孔径进行选择性运输（消耗能量）
```
