# 第5章 细胞的能量供应和利用
## 第 3 节 细胞呼吸的原理和应用
### 细胞呼吸的方式
>酵母菌在有氧和无氧条件下都能进行细胞呼吸。
>
>在有氧条件下，酵母菌通过细胞呼吸产生大量的二氧化碳和水； 
>在无氧条件下，酵母菌通过细胞呼吸产生酒精，还产生少量的二氧化碳。 
>科学家根据大量的实验结果得出结论：细胞呼吸可分为 有 氧 呼 吸（aerobic respiration） 和 无 氧 呼 吸（anaerobic respiration）两种类型

[[探究·实践/探究酵母菌细胞呼吸的方式]]



### #有氧呼吸
有氧呼吸是细胞在氧气参与下，通过多种酶的催化作用将葡萄糖等有机物彻底氧化分解为 $\text{CO}_2$ 和 $\text{H}_2\text{O}$，并释放能量合成 ATP 的生理过程。
#### 有氧呼吸的三个阶段

**第一阶段：糖酵解阶段（葡萄糖分解）**

- **发生场所：** 细胞质基质
    
- **过程解析：** 1 分子葡萄糖在酶的催化下分解为 2 分子丙酮酸，同时脱下 4 个 $[\text{H}]$（主要为还原型辅酶 1$\text{NADH}$），释放少量能量。
    
- **反应方程式：**
    
    $$\text{C}_6\text{H}_{12}\text{O}_6 \xrightarrow{\text{酶}} 2\text{C}_3\text{H}_4\text{O}_3 + 4[\text{H}] + \text{少量能量}$$
    

**第二阶段：三羧酸循环阶段（丙酮酸彻底分解）**

- **发生场所：** 线粒体基质
    
- **过程解析：** 丙酮酸进入线粒体基质，与水分子结合彻底分解为 $\text{CO}_2$，同时脱下大量 $[\text{H}]$（产生 $\text{NADH}$ 和 $\text{FADH}_2$），释放少量能量。
    
- **反应方程式：**
    
    $$2\text{C}_3\text{H}_4\text{O}_3 + 6\text{H}_2\text{O} \xrightarrow{\text{酶}} 6\text{CO}_2 + 20[\text{H}] + \text{少量能量}$$
    

**第三阶段：电子传递链与氧化磷酸化（$[\text{H}]$ 与氧结合）**

- **发生场所：** 线粒体内膜
    
- **过程解析：** 前两阶段积累的 24 个 $[\text{H}]$ 沿电子传递链传递给 $\text{O}_2$，结合生成水。电子传递建立的跨膜质子梯度驱动 ATP 合成酶，释放出绝大部分能量。
    
- **反应方程式：**
    
    $$24[\text{H}] + 6\text{O}_2 \xrightarrow{\text{酶}} 12\text{H}_2\text{O} + \text{大量能量}$$
    

**三阶段核心特征对比**

| **阶段**   | **发生场所** | **反应物**                   | **主要产物**                   | **能量释放**           | **是否需要 O2​**                 |
| -------- | -------- | ------------------------- | -------------------------- | ------------------ | ---------------------------- |
| **第一阶段** | 细胞质基质    | 葡萄糖                       | 丙酮酸、$[\text{H}]$           | 少量 (生成 2 ATP)      | 否                            |
| **第二阶段** | 线粒体基质    | 丙酮酸、$\text{H}_2\text{O}$  | $\text{CO}_2$、$[\text{H}]$ | 少量 (生成 2 ATP)      | 否（但间接依赖有氧环境）                 |
| **第三阶段** | 线粒体内膜    | $[\text{H}]$、$\text{O}_2$ | $\text{H}_2\text{O}$       | 大量 (生成约 28~34 ATP) | **是**（$\text{O}_2$ 作为最终电子受体） |


**总反应方程式**

$$\text{C}_6\text{H}_{12}\text{O}_6 + 6\text{H}_2\text{O} + 6\text{O}_2 \xrightarrow{\text{酶}} 6\text{CO}_2 + 12\text{H}_2\text{O} + \text{能量}$$

**注：原核生物没有线粒体，进行有氧呼吸相关的酶分布在细胞质基质和细胞膜上，因此原核生物有氧呼吸的场所是细胞质基质和细胞膜**


### #无氧呼吸
无氧呼吸是指细胞在无氧条件下，通过酶的催化作用将葡萄糖等有机物进行**不彻底氧化分解**，产生酒精和 $\text{CO}_2$ 或乳酸，并释放少量能量的过程。整个过程全部在**细胞质基质**中完成。

#### **无氧呼吸的两个阶段**

- **第一阶段（糖酵解阶段）**
    
    - **发生场所：** 细胞质基质
        
    - **过程解析：** 与有氧呼吸第一阶段完全相同。1 分子葡萄糖分解为 2 分子丙酮酸，脱下 4 个 $[\text{H}]$，释放少量能量（生成 2 个 ATP）。
        
    - **反应式：**
        
        $$\text{C}_6\text{H}_{12}\text{O}_6 \xrightarrow{\text{酶}} 2\text{C}_3\text{H}_4\text{O}_3 + 4[\text{H}] + \text{少量能量}$$
        
- **第二阶段（丙酮酸还原阶段）**
    
    - **发生场所：** 细胞质基质
    - **无氧呼吸第二阶段的反应方程式**（丙酮酸还原阶段）：

	- **酒精发酵途径（生成酒精与 $\text{CO}_2$）：**
    $$2\text{C}_3\text{H}_4\text{O}_3 + 4[\text{H}] \xrightarrow{\text{酶}} 2\text{C}_2\text{H}_5\text{OH} + 2\text{CO}_2$$
    
	- **乳酸发酵途径（生成乳酸）：**
    $$2\text{C}_3\text{H}_4\text{O}_3 + 4[\text{H}] \xrightarrow{\text{酶}} 2\text{C}_3\text{H}_6\text{O}_3$$

	_(注：反应中的 $4[\text{H}]$ 完全消耗第一阶段产生的 $[\text{H}]$，此阶段**不释放能量**，也**不生成 ATP**。)_


**无氧呼吸的两条途径**

| **类型**   | **产物**                                               | **总反应方程式**                                                                                                             | **常见生物 / 特殊器官**                        |
| -------- | ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- | -------------------------------------- |
| **酒精发酵** | 酒精 ($\text{C}_2\text{H}_5\text{OH}$) + $\text{CO}_2$ | $\text{C}_6\text{H}_{12}\text{O}_6 \xrightarrow{\text{酶}} 2\text{C}_2\text{H}_5\text{OH} + 2\text{CO}_2 + \text{少量能量}$ | 酵母菌、**大多数植物**、苹果果实等                    |
| **乳酸发酵** | 乳酸 ($\text{C}_3\text{H}_6\text{O}_3$)                | $\text{C}_6\text{H}_{12}\text{O}_6 \xrightarrow{\text{酶}} 2\text{C}_3\text{H}_6\text{O}_3 + \text{少量能量}$               | 乳酸菌、人与动物骨骼肌（剧烈运动缺氧）、**马铃薯块茎、甜菜块根、玉米胚** |

**核心特征与能量转化**

- **能量利用率低：** 1 分子葡萄糖进行无氧呼吸仅产生 **2 个 ATP**（全部来自第一阶段），大部分能量仍储存在未彻底分解的有机产物（酒精或乳酸）中。
    
- **场所单一：** 有氧呼吸跨越细胞质基质和线粒体，而无氧呼吸全过程均在**细胞质基质**中发生。
    
- **器官特异性：** 同一植物的不同器官可能进行不同类型的无氧呼吸（例如马铃薯地上茎叶缺氧进行酒精发酵，而地下块茎缺氧则进行乳酸发酵）。










## 第 4 节 光合作用与能量转化
### 捕获光能的色素和结构
#### #光合色素

- 绿叶中的色素（这里的都是**脂溶性色素**）
	- 叶绿素 （**含量约占 3/4**）：吸收光能并将其转化为化学能。**主要吸收：** **红光**和**蓝紫光**
		- 叶绿素 a（**蓝绿色**）
		- 叶绿素 b（**黄绿色**)
	- 类胡萝卜素（**含量约占 1/4**）：在强光下，它们能吸收过剩的能量并将其以热量形式释放，防止强光破坏叶绿素和光合系统。**主要吸收：** **蓝紫光**
		- 胡萝卜素（**橙黄色**）
		- 叶黄素（**黄色**）


- 在有机溶剂里的溶解度：
	- 胡>黄>a>b

- 光合色素的功能：  **吸收、传递、转化光能**

#### #光合作用的原理
**光反应阶段（依赖光照,==吸收、传递、转化光能==）**

- **发生场所**：**叶绿体类囊体薄膜**（Thylakoid Membrane）。
    
- **能量转换**：光能 $\rightarrow$ ATP 和 NADPH 中的活跃化学能。
    
- **核心反应**：
    
    - **水的光解**：类囊体膜上的色素吸收光能后激发电子传递，水分子被裂解产生氧气、质子（$\text{H}^+$）与电子：
        
        $$2\text{H}_2\text{O} \xrightarrow{\text{光能、色素}} 4\text{H}^+ + 4\text{e}^- + \text{O}_2\uparrow$$
        
        生成的氧气释放到细胞外，是大气中氧气的主要来源。
        
    - **ATP 和 NADPH 的合成**：高能电子在电子传递链中转移，驱动质子跨膜运输形成浓度梯度，促使 $\text{ADP} + \text{P}_i \rightarrow \text{ATP}$；同时 $\text{NADP}^+$ 接受电子和质子被还原为 NADPH（还原型辅酶Ⅱ）。

**暗反应阶段（卡尔文循环，不直接依赖光）**

- **发生场所**：**叶绿体基质**（Stroma）。
    
- **能量转换**：ATP 和 NADPH 中的活跃化学能 $\rightarrow$ 有机物中的稳定化学能。
    
- **核心反应**：
    
    - **$\text{CO}_2$ 的固定**：环境中的 $\text{CO}_2$ 进入基质后，在 **Rubisco 酶**的催化下与五碳化合物（$\text{C}_5$，即 RuBP）结合，迅速生成两分子三碳化合物（$\text{C}_3$）。
        
    - **$\text{C}_3$ 的还原**：$\text{C}_3$ 接受光反应提供的 ATP 能量与 NADPH 的氢，被还原为三碳糖（G3P），随后，一些接受能量并被还原的 C3，在 酶的作用下经过一系列的反应转化为糖 **(ATP、NADPH 和相关的酶共同作用)**
        
    - **$\text{C}_5$ 的再生**：部分三碳糖经过一系列复杂的酶促反应重新转化为 $\text{C}_5$，维持卡尔文循环持续进行。 **(ATP和相关的酶共同作用)**
